This built-in bundle vendors the HTML, local fonts/vendor JS, mascot frames, snapshots, and Framepack metadata needed for template reuse.

Render MP4 files from the workbench are intentionally excluded from the plugin bundle to keep the package small; users can render fresh output in their own project.

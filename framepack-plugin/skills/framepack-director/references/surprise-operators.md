# Controlled Surprise Operators

Controlled Surprise creates personality through intentional deviation. Surprise is chili, not the main dish.

Rules:

- Recommended, not mandatory.
- Use at most 1-2 per video.
- Must include `intent` when declared in `frame.md` as `surprise_operator`.
- Execution Manifest scene-level `surprise:` is a semantic tag copied from the Director plan; it does not require per-scene `intent`.
- Must serve brand/story and remain implementable in HyperFrames/GSAP.

Operators:

- `scale_violation` — Scale Violation / 尺度冒犯. Element scale becomes intentionally unreasonable.
- `tempo_break` — Tempo Break / 节奏断裂. Suddenly break established pacing.
- `material_shift` — Material Shift / 材质突变. Element changes material language.
- `spatial_flip` — Spatial Flip / 空间翻转. Flat composition unfolds into spatial depth.
- `negative_space_shock` — Negative Space Shock / 留白震荡. Sudden emptiness becomes impact.
- `misdirection` — Misdirection / 误导转向. Set expectation A, reveal B.
- `motif_mutation` — Motif Mutation / 母题变异. Recurring motif mutates toward final payoff.
- `abrupt_stillness` — Abrupt Stillness / 突然凝固. Freeze after high motion.
- `imperfect_human_touch` — Imperfect Human Touch / 非机械手感. Controlled imperfection avoids sterile motion.
- `impossible_transition` — Impossible Transition / 不可能转场. One scene element impossibly becomes the next subject.

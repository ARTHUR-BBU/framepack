# Reference Specimens

Reference specimens are not templates. They are compact DNA references that help Director choose visual physics, kinetic grammar, taste moves, and controlled surprise.

## Built-in MVP specimens

- `luxury_object_emergence` — Luxury Object Emergence. For jewelry, beauty, premium product reveal. Uses object worship, slow-burn reveal, halo/portal transitions.
- `interface_ballet_saas` — Interface Ballet SaaS. For SaaS, devtools, product UI. UI cards and mockups move like choreographed performers.
- `kinetic_type_event` — Kinetic Type Event. For conferences, launch, announcements. Typography is the motion subject.
- `data_cathedral_explainer` — Data Cathedral Explainer. For AI/data/analytics. Data becomes spatial architecture.
- `liquid_brand_story` — Liquid Brand Story. For brand film, wellness, beauty, soft tech. Brand lines flow as ribbons/light.
- `cold_open_mystery` — Cold Open Mystery. For teasers and cinematic intros. Starts with a visual question before copy.

Use 1-2 `reference_dna` IDs in frame.md. Do not copy a specimen as a template; translate its DNA into the user's brand world.

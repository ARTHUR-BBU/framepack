# Kinetic Grammar

Kinetic grammar describes how actions connect across elements and scenes. It prevents animation from becoming isolated entrance effects.

- `cause_reveal` — Cause → Reveal / 因果显形. One visual action causes another element to appear.
- `echo_transform` — Echo → Transform / 回声变形. A shape returns in a transformed role.
- `mask_portal` — Mask → Portal / 遮罩开门. A transition opens like a doorway, not a plain fade.
- `tension_release` — Tension → Release / 蓄力释放. Restraint builds pressure before impact.
- `scatter_assemble` — Scatter → Assemble / 散点组装. Fragments disperse or orbit before assembling meaning.
- `follow_through` — Follow-through / 惯性接力. One motion's inertia carries the next element.
- `breath_punch_silence` — Breath → Punch → Silence / 吸气出拳停顿. Inhale, impact, held stillness.

Every expanded-prompt should use kinetic grammar to explain at least two scene boundaries. Avoid generic fade stacks.

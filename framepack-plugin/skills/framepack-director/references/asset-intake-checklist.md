# Asset Intake Checklist — 条件深度指南

> 按视频类型决定问什么、问多深。不是每次都全六类收集。

## 六类素材速查

| 品类 | 包含什么 |
|------|---------|
| 品牌身份 | Logo、品牌色、品牌字体、VI 规范 |
| 产品素材 | 产品图（扣过/没扣图）、3D 渲染、生活方式照 |
| 视频素材 | 实拍片段、现成视频、屏幕录制 |
| 文案内容 | Slogan、卖点列表、产品描述、CTA、品牌故事 |
| 音频 | 授权 BGM、旁白音频、旁白文案、音乐偏好 |
| 参考 | 参考视频链接、竞品视频、情绪板 |

---

## 按视频类型的收集深度

### brand_product_launch（品牌产品发布/推广/广告）

**全六类，必须问：**

1. 品牌身份
   - "你有 logo 吗？什么格式？SVG 最好，PNG 透明底也行。"
   - "有品牌色吗？hex 值或 VI 手册都行。"
   - "有指定字体吗？"

2. 产品素材
   - "有产品图吗？扣过图的（透明底 PNG）还是带背景的？"
   - "有几张？分别是什么角度/场景？"
   - "有 3D 渲染图吗？"

3. 视频素材
   - "有实拍素材吗？产品使用场景、工厂、团队都行。"
   - "有没有已经做好的视频片段想植入的？"

4. 文案内容
   - "品牌 slogan 是什么？"
   - "产品核心卖点给我 3-5 条。"
   - "有 CTA（行动号召）吗？比如'立即购买'、'了解更多'。"
   - "有品牌故事想讲吗？"

5. 音频
   - "有授权的 BGM 吗？"
   - "需要旁白吗？有旁白文案还是用 TTS 生成？"
   - "BGM 风格偏好？"

6. 参考
   - "有参考视频吗？'我想要这种感觉'那种。"
   - "有竞品视频可以参考吗？"

### educational（概念/教育/科普视频）

**三类，聚焦信息：**

1. 文案内容
   - "要表达什么信息？给我核心内容大纲。"
   - "有需要展示的数据/图表吗？"
   - "有总结/结论文案吗？"

2. 音频
   - "需要旁白吗？有文案还是用 TTS？"
   - "BGM 偏好？"

3. 参考
   - "有参考视频吗？"
   - "有喜欢的科普频道风格吗？（Kurzgesagt? 3Blue1Brown?）"

### social_teaser（社交媒体速递/Story）

**四类，轻量快速：**

1. 品牌身份
   - "Logo 有吗？品牌色呢？"

2. 文案内容
   - "一句话核心文案是什么？"
   - "CTA 是什么？"

3. 产品素材
   - "一张关键图就行——选哪张？"

4. 音频
   - "BGM 有偏好吗？"

### kinetic_type（纯文字/动效视频）

**最小化：**

1. 文案内容
   - "文字稿给我。每句话的时间分配有什么要求吗？"

2. 音频
   - "BGM 偏好？需要旁白吗？"

## 视频类型自动判定

根据用户第一句话判定：

| 用户说 | 判定 |
|--------|------|
| "做个 XX 品牌新品发布视频" | brand_product_launch |
| "做个产品广告/推广" | brand_product_launch |
| "解释一下什么是 XX" | educational |
| "做个教程/科普" | educational |
| "做个 15 秒 Instagram/抖音推广" | social_teaser |
| "做个动感的文字动画" | kinetic_type |
| "做个 Keynote 片头" | brand_product_launch |

无法判定时，直接问："这个视频是品牌推广？知识科普？还是社交媒体内容？"

## 透明通道检测

用户给图片后，按格式判断：

| 格式 | 透明通道 | 处理 |
|------|---------|------|
| SVG | 天然透明 | 直接用 ✅ |
| PNG/WebP（有 alpha） | 有透明 | 直接用 ✅ |
| PNG/WebP（无 alpha） | 无透明 | 标记 needs_processing，建议 `npx hyperframes remove-background` |
| JPG | 无透明通道 | 标记 needs_processing，建议 `npx hyperframes remove-background` |

**Framepack 只检测+建议，不自动执行 remove-background。** Agent 决定何时处理。

## 优雅降级

### 用户什么都没有

```
"没有 logo，没有产品图，什么都没有"
→ "没问题。给我一句话核心文案，做个纯文字动效视频。"
→ 降级到 kinetic_type，intake_depth: minimal
```

### 用户只有部分

```
"有 logo 但没产品图"
→ "行，logo 够了。产品图可以用动效模拟展示。"
→ partial intake，missing 列表标注 product_images
```

### 用户给的是链接不是文件

```
"logo 在我们官网上"
→ Agent 下载到 assets/ → 检测格式 → 注册到 manifest
```

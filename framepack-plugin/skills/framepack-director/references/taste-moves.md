# Director Taste Moves

Taste Moves are directing techniques, not templates.

- `object_worship` — Object Worship / 物件崇拜. Treat the product like sculpture.
- `editorial_punch` — Editorial Punch / 杂志重拳. Oversized type as a kinetic event.
- `silence_before_drop` — Silence Before Drop / 爆发前静默. Restraint before release.
- `motif_reincarnation` — Motif Reincarnation / 母题转生. A visual motif changes form across scenes.
- `interface_ballet` — Interface Ballet / 界面编舞. UI/mockups move like choreographed performers.
- `data_cathedral` — Data Cathedral / 数据圣殿. Data becomes architecture, not flat charts.
- `liquid_brand` — Liquid Brand / 液态品牌. Brand elements flow as liquid/ribbons/light.
- `cold_open` — Cold Open / 冷开场. Start with a visual question before explanation.
- `kinetic_typography_attack` — Kinetic Typography Attack / 动态字体攻击. Type is the main moving subject.
- `product_reveal_ritual` — Product Reveal Ritual / 产品揭幕仪式. Product entrance feels ceremonial.
- `system_awakening` — System Awakening / 系统苏醒. Technical product wakes from grid/signal/boot.
- `human_imperfection` — Human Imperfection / 人味瑕疵. Controlled irregularity adds hand feel.

Use 1-3 moves per video. Too many moves dilute the personality.

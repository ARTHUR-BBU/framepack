# Storyboard Completeness Checklist

Per-project-type checklists for validating a STORYBOARD.md.

## Event Promo (Summit / Conference / Webinar / Salon / Livestream)

- [ ] Opening hook: What's the strongest promise or most exciting moment?
- [ ] Event value: Why should the viewer care about this event?
- [ ] Speakers / agenda: Who's on stage? What will they talk about?
- [ ] Venue energy: Where is it happening? (even virtual — show the vibe)
- [ ] Countdown / urgency: When is it? Is there a deadline?
- [ ] CTA: How do they register? QR code? Link? Button?
- [ ] Minimum 5 scenes (hook, value, speakers, countdown, CTA)

## Sports Highlight (Basketball / Football / Esports)

- [ ] Opening impact: Best moment first (the dunk, the goal, the clutch play)
- [ ] Player focus: Who's the hero? Name, number, position
- [ ] Dramatic beats: Key turning points — not every play, just the story
- [ ] Stats card: Numbers that tell the story (PPG, win rate, record)
- [ ] CTA: Follow / watch schedule / subscribe
- [ ] Minimum 4 scenes (impact, player, drama, stats/CTA)

## Transfer Announcement

- [ ] Player reveal: Face, kit, iconic celebration or pose
- [ ] Stats card: Goals, assists, caps, age — numbers that matter
- [ ] Previous club nod: Respectful acknowledgment
- [ ] New club badge + fan reaction: The emotional payoff
- [ ] CTA: Welcome message / follow for more
- [ ] Minimum 4 scenes (reveal, stats, badge, CTA)

## SaaS / Product Launch

- [ ] Problem hook: What pain point does this solve?
- [ ] Solution reveal: How it solves it — the "aha" moment
- [ ] Feature cards: Top 3 features, each with visual support
- [ ] Social proof: Numbers, quotes, logos, case study blurbs
- [ ] CTA: Try / Buy / Sign up — with clear next step
- [ ] Minimum 5 scenes (problem, solution, features × 2, CTA)

## Course / Education Promo

- [ ] Pain point: What skill gap or frustration does this course address?
- [ ] Teacher reveal: Who's teaching? Credibility, personality
- [ ] Curriculum overview: What will they learn? 3-5 key modules
- [ ] Testimonials / results: "Went from X to Y in Z weeks"
- [ ] CTA: Enroll now, limited spots, next session starts...
- [ ] Minimum 5 scenes (pain, teacher, curriculum, testimonial, CTA)

## News / Data Explainer

- [ ] Headline hook: The most surprising or important fact
- [ ] Context: Why this matters now — the "so what"
- [ ] Key data: Numbers, charts, comparisons — visual first
- [ ] Expert angle: Quote or perspective from a credible source
- [ ] Outlook / CTA: What happens next? Share / follow / read more
- [ ] Minimum 4 scenes (hook, context, data, outlook)

## Data Shock

- [ ] Big number reveal: The single most shocking stat
- [ ] Comparison: What does this number mean in context?
- [ ] Implication: Why the viewer should care about this
- [ ] Source: Where did this data come from? (credibility)
- [ ] CTA: Share / discuss / learn more
- [ ] Minimum 4 scenes (number, comparison, implication, CTA)

## Universal Checks (All Project Types)

- [ ] No placeholder text ("Lorem ipsum", "TODO", "TKTK")
- [ ] Each scene has a clear visual description (not just "text on screen")
- [ ] Scene timing feels right (no scene is <1s or >15s without reason)
- [ ] Pacing varies — fast cuts for energy, slow for emotional beats
- [ ] Music / audio cues are noted (even if just "beat drop here" or "silent moment")
- [ ] `meta.json` target resolution is consistent with storyboard aspect ratio

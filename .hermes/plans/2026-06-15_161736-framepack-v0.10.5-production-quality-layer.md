# Framepack v0.10.5 Production Quality Layer Implementation Plan

> **For Hermes:** Execute task-by-task with strict TDD. Do not commit unless user explicitly asks. Keep v0.10.4 and v0.10.5 changes distinguishable.

**Goal:** Build Framepack v0.10.5's Production Quality Layer: timeline manifest, proof tooling, scene-spec/change-request templates, continuity/productivity skills, and Quality Audit extensions.

**Architecture:** Add a lightweight production metadata layer around existing Framepack handoff outputs. `frame.md` and `.hyperframes/expanded-prompt.md` remain creative outputs; `.framepack/arsenal.json` remains the weapon ledger; new `.framepack/timeline-manifest.json` becomes the scene/time/proof/lock ledger. Framepack stays report-first and does not write/patch/render HTML.

**Tech Stack:** Python 3.11, pytest, existing Framepack plugin layout under `framepack-plugin/`, CLI scripts under `framepack-plugin/scripts/`, plugin skills under `framepack-plugin/skills/`.

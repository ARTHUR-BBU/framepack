# Framepack 0.6.x To 0.7.0 Roadmap Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make Framepack 0.6.x a product-grade internal-testable programmatic-video Agentic Workflow Harness before 0.7.0 starts long-loop self-maintenance work.

**Architecture:** Framepack remains an add-on Harness layered on Codex and Claude Code. The 0.6.x center is `Workbench Files -> Internal Lifecycle Hooks -> Audit Gates -> interventionContext -> Agent Action`, with project-local evidence in `.framepack/`.

**Tech Stack:** TypeScript CLI, workbench Markdown files, HyperFrames runtime contract, MCP surface, agent skills, sandbox benchmark.

## Boundary Before 0.7.0

Do not implement before 0.7.0:

- global daemon
- always-on chat monitoring
- cross-project personal memory
- automatic host-agent config mutation
- third-party auto-installation
- open `registerHook()` plugin API
- public hook lifecycle contracts

0.6.x installs the city's red lights and road sensors. 0.7.0 can later consider letting trusted ecosystem participants propose new intersections.

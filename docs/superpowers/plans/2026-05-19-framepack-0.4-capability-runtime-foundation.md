# Framepack 0.4 Capability Runtime Foundation Implementation Plan

Framepack 0.4 is the practical implementation of a video production Agent Harness. Codex and Claude Code are the general-purpose brains; Framepack supplies the domain-specific nervous system that lets those brains see video-production state, choose controlled actions, persist memory, and verify results with evidence.

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the Framepack 0.4 capability runtime foundation, starting with package-level capability graphs and then layering runtime manifests, template packs, motion grammar, visual QA evidence, and Asset Forge Loop V2.

**Architecture:** Extend the existing package protocol without breaking v1 packages. New 0.4 artifacts are generated as additive package files, indexed in `PACKAGE_MANIFEST.json`, validated by package validation, surfaced through `status --json`, and exposed through MCP only when the data is structured. The first executable slice is `CAPABILITY_GRAPH.json`; subsequent slices depend on that graph instead of inventing separate discovery paths.

**Tech Stack:** TypeScript, Node.js, Framepack package protocol, MCP SDK, HyperFrames runtime adapter, existing `scripts/run-tests.mjs` test harness.

---

## Harness Alignment

Implementation work should keep the five-part Agent Harness model explicit:

| Harness dimension | Implementation priority |
| --- | --- |
| Sense filter | `CAPABILITY_GRAPH.json`, capability summaries, capability gaps, and delivery modes. |
| Motor pathways | MCP tools and CLI commands that return structured state rather than wrapping human logs. |
| Reflexes | validation, repair, runtime lint, runtime inspect, and capability scans that catch drift early. |
| Memory encoding | package artifacts that make every intermediate product recoverable and handoff-friendly. |
| Feedback loop | runtime inspect reports, snapshot manifests, visual QA notes, and validation reports. |

Do not add features as isolated commands. Tie each 0.4 artifact or tool back to one harness dimension and make the artifact readable by a coding agent.

- [ ] **Step 3: Implement the minimal builder**

Create `src/capabilities/capability-graph.ts`:

```ts
export type CapabilityKind = "runtime" | "library" | "cli" | "mcp-tool" | "skill" | "remote-api" | "manual";

export type CapabilityDelivery =
  | "npm-local"
  | "cdn-runtime"
  | "cli-local"
  | "mcp-tool"
  | "remote-api"
  | "codex-skill"
  | "manual-external";

export type CapabilityStatus = "available" | "planned" | "not-detected" | "external" | "blocked";

export interface CapabilityNode {
  id: string;
  kind: CapabilityKind;
  provider: string;
  delivery: CapabilityDelivery;
  required: boolean;
  status: CapabilityStatus;
  usedBy: string[];
}

export interface CapabilityEdge {
  from: string;
  to: string;
  reason: string;
}

export interface CapabilityGraph {
  version: "framepack.capability-graph.v1";
  nodes: CapabilityNode[];
  edges: CapabilityEdge[];
}

export function buildCapabilityGraph(input: {
  sourceType: string;
  outputType: string;
  executionKinds: string[];
  forgeBackends: string[];
  requiredSkills: string[];
  runtimeBackend: string;
  packageCommands: string[];
}): CapabilityGraph {
  const nodes: CapabilityNode[] = [
    {
      id: "video-runtime.hyperframes",
      kind: "runtime",
      provider: input.runtimeBackend,
      delivery: "npm-local",
      required: true,
      status: "available",
      usedBy: input.packageCommands,
    },
    {
      id: "mcp.framepack",
      kind: "mcp-tool",
      provider: "framepack",
      delivery: "mcp-tool",
      required: false,
      status: "available",
      usedBy: ["generateProject", "getStatus", "validatePackage"],
    },
  ];

  for (const backend of input.forgeBackends) {
    nodes.push({
      id: `asset-forge.${backend}`,
      kind: "skill",
      provider: backend,
      delivery: backend === "agent-sprite-forge" ? "codex-skill" : "manual-external",
      required: false,
      status: "not-detected",
      usedBy: input.executionKinds.filter((kind) => kind.startsWith("forge-")),
    });
  }

  for (const skill of input.requiredSkills) {
    nodes.push({
      id: `skill.${skill}`,
      kind: "skill",
      provider: skill,
      delivery: "codex-skill",
      required: false,
      status: "not-detected",
      usedBy: input.executionKinds.filter((kind) => kind.startsWith("forge-")),
    });
  }

  return {
    version: "framepack.capability-graph.v1",
    nodes,
    edges: nodes
      .filter((node) => node.id !== "video-runtime.hyperframes")
      .map((node) => ({
        from: node.id,
        to: "video-runtime.hyperframes",
        reason: `${node.id} supports ${input.outputType} package production before HyperFrames runtime verification.`,
      })),
  };
}
```

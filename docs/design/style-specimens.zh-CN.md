# Framepack 中文风格样板规格

## 视觉命题

八张样板像八位不同性格的摄影指导：共用同一段中文产品信息和同一套本地字体，但通过网格、尺度、材质、色彩与运动节奏，形成一眼可辨的导演语言。

## 内容计划

每张 5 秒样板只承担四件事：显示风格中文名、给出一句产品主张、呈现一个主视觉动作、在结尾留下适用场景。禁止把样板做成参数卡片或后台面板。

## 交互与运动命题

1. 统一使用 HyperFrames 可寻址的 paused GSAP timeline，确保任意时间点可复现。
2. 每种风格只使用一个主动作和一个环境动作；高能风格强调切入与尺度，安静风格强调显形与呼吸。
3. 横向比较时保持相同信息量和 5 秒时长，让差异来自设计语言而非内容作弊。

## 八种人格

| 风格 | 主构图 | 主动作 |
|---|---|---|
| 瑞士脉冲 | 严格左对齐网格与超大编号 | 标题快速切入，网格线推进 |
| 丝绒标准 | 深色舞台与金色焦点 | 产品式缓慢显形 |
| 解构工业 | 偏轴文字、切割面与工业标记 | 图层错位咬合 |
| 极繁字体 | 满版宣言与强撞色 | 大字尺度冲击 |
| 数据漂移 | 深蓝数据空间与轨迹 | 信号点沿轨迹漂移 |
| 柔和信号 | 暖纸色与局部柔光 | 内容呼吸式浮现 |
| 民俗频率 | 手作几何纹样与社区色彩 | 图形按节拍轮转 |
| 暗影切面 | 黑场、硬边光与局部显形 | 遮罩切面揭示 |

## 验收口径

- 8 份样板均使用中文界面文字和本地 Noto Sans SC 字体。
- 每份通过 `hyperframes lint` 与 `hyperframes check`。
- 每份保存至少三个时间点截图和 contact sheet。
- 不能依赖网络字体、CDN、随机数、ScrollTrigger 或无限循环。

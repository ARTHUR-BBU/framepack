# Framepack MCP Tools

Framepack exposes an MCP stdio server with tools for the complete package lifecycle:

- `generateProject`
- `getStatus`
- `validatePackage`
- `repairPackage`
- `captureAssets`
- `syncAssets`
- `runtimeDoctor`
- `runtimeLint`
- `runtimeInspect`
- `runtimeSnapshot`
- `explainNextActions`

It also exposes project resources for manifest, handoff, asset execution plan, forge tasks, and status.

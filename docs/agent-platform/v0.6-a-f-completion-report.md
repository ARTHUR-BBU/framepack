# Framepack 0.6 A-F Milestone Completion Report

> ID: V0.6-AF-COMPLETION-01
> Version: 0.6.0-alpha.3
> Scope: A-F milestone closure before 0.6.0-beta.1

## Summary

Framepack 0.6 now has a complete project-local Agentic Workflow Harness loop:

```text
idea + assets + references
  -> workbench files
  -> active intervention context
  -> lifecycle gates
  -> friction/learnings/preferences
  -> template/Catalog recommendations
  -> HyperFrames build/preview path
  -> manual trials and beta gate evidence
```

Plain-language summary: Framepack is no longer just writing video project files. It now behaves more like a production supervisor for programmatic video work: it tells the agent what to read, blocks risky jumps, records repeated problems, remembers user taste, and gives testers a repeatable way to judge whether the project can move toward beta/customer trials.

## Code Audit Notes

### Scope Reviewed

- CLI lifecycle behavior: `src/interfaces/cli/index.ts`
- Workbench supervision: `src/workbench/interventions.ts`, `src/workbench/friction.ts`, `src/workbench/preferences.ts`
- Agent-facing docs: `README.md`, `docs/README.zh-CN.md`, `AGENTS.md`, `templates/agent/codex/SKILL.md`, `templates/agent/claude-code/CLAUDE.md`
- Product tests: `scripts/run-tests.mjs`

### Findings

- P0: none found in the current 0.6 workbench path.
- P1: none found in the current structural beta gate.
- P2: legacy 0.4 package-protocol commands remain in code and docs for compatibility; they are explicitly marked as non-primary onboarding path.
- P2: full visual QA still needs real browser/video review with actual user assets before public beta confidence, even though structural build/preview gates pass.

### Guardrails Added

- Chinese README and package readme reject common mojibake patterns in tests.
- Workbench trials require SaaS launch, course promo, and data/news explainer paths.
- Repeated friction categories become P1 `recurringRisks`.
- `AGENTS.md` and skills instruct agents to stop customer handoff when recurring risks exist.

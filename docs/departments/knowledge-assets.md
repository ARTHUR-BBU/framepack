# Knowledge Assets Department

> Role: the recipe archive. Turn every good case into a reusable asset.
>
> Plain-English job: Knowledge Assets is the librarian + archivist. It makes sure the company doesn't reinvent the wheel every time. Templates, reference DNA, visual styles, and case learnings live here.

## 1. Department boundary

Knowledge Assets owns **reusable production assets**:

- Template Arsenal: builtin and installed templates.
- Reference Miner output: motion DNA extracted from reference videos.
- Visual style profiles.
- Case learnings and research PRDs.
- External research absorption (e.g. Taste Skill, Impeccable).

Knowledge Assets does **not** own:

- creative direction for a specific project — Director Bible owns that
- unvalidated one-off tricks — those stay as experiments until proven

## 2. Contracts

| Direction | Artifact | Consumer |
|---|---|---|
| Output | registered templates | Intent & Intake (template menu) |
| Output | reference DNA | Director Bible (style matching) |
| Output | visual style profiles | Director Bible (frame.md) |
| Output | case learnings | all departments (improvement feedback) |
| Input | successful cases | from production projects |
| Input | rendered proof | from Production Audit |

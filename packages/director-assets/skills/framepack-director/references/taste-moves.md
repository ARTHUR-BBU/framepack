# 口味动作

每支片选一至三个，过多会稀释性格。

- `object_worship`：把产品当雕塑拍。
- `editorial_punch`：让超大字体成为事件。
- `silence_before_drop`：爆发前刻意静默。
- `motif_reincarnation`：母题跨场景转生。
- `interface_ballet`：界面像演员一样编舞。
- `data_cathedral`：让数据成为空间建筑。
- `liquid_brand`：品牌元素像液体、丝带或光流动。
- `cold_open`：先抛视觉问题，再解释。
- `kinetic_typography_attack`：让文字成为主要运动主体。
- `product_reveal_ritual`：把产品登场做成仪式。
- `system_awakening`：系统从网格、信号或启动状态苏醒。
- `human_imperfection`：用可控的不规则增加人味。
